# GSIM 主流程（`src/main.cpp` 第 149 行起）

从 FIRRTL AST 转成内部图后，`main` 依次执行下列阶段，对同一张设计图不断精简和重构，最终生成 C++：

1) `splitArray`  
   - 将多维数组节点拆成标量节点，复制相关赋值/复位树，并重新连接依赖，避免数组自环阻塞拓扑排序并为后续切分做准备。

2) `detectLoop`  
   - 对初始超节点图做 DFS 检测（允许 0 延迟读端口的自环），发现组合环立即报错。

3) `topoSort`  
   - 按依赖关系对 `SuperNode` 拓扑排序，写入 `sortedSuper` 和节点序号，奠定之后所有遍历顺序。

4) `inferAllWidth`  
   - 反复推导每个节点及表达式的位宽/符号/时钟属性，必要时回推重算，直到宽度收敛并同步寄存器源/目的宽度。

5) `removeDeadNodes`（多次出现）  
   - 以输出/外设/特殊节点为根回溯标记可达节点；未被使用的计算、寄存器、端口等标为 DEAD 并清理连接。

6) `exprOpt`  
   - 局部表达式简化：合并相同分支的 `when/mux`，去掉等价的类型转换/异步复位包裹，0 位宽转常量等。

7) `usedBits`  
   - 从出口向前传播“真正被用到的位数”，收紧节点和表达式的宽度、同步 reset 树，并刷新宽度不匹配处。

8) `splitNodes`  
   - 按位切分宽节点/寄存器（基于组件与段信息），复制/重写表达式与连接，便于 CSE 和分区减少跨界依赖。

9) `constantAnalysis`  
   - 常量传播与折叠：计算 `valInfo`，将可确定的节点标记为常量，简化 `when/reset`/聚合操作并删除常量化的节点。

10) `aliasAnalysis`  
    - 识别纯别名（如单赋值/数组别名）节点，用源表达式替换其出现处，删除冗余节点。

11) `patternDetect`  
    - 针对特定模式重写（如 one-hot 生成再按位取、Cat/Or 与常量比较拆成分段比较），并回收被替换的节点。

12) `commonExpr`  
    - 跨节点的公共子表达式消除：基于哈希和等价检查合并语义相同的计算，使用别名替换并删除副本。

13) `graphPartition`  
    - 超节点分区：先粗化（合并 when/reset/out/in 等），再用 DP 依据 `SuperNodeMaxSize` 划分块，随后按收益移动节点细化，减少跨分区边。

14) `replicationOpt`  
    - 对廉价、扇出大的节点复制到消费者所在超节点，减少跨分区激活边；被吸收的原节点标记回收。

15) `generateStmtTree`  
    - 将每个节点的表达式/条件组合成层次化的语句树 `StmtTree`，按依赖路径对齐 when/else 序列，供指令生成使用。

16) `instsGenerator`  
    - 在拓扑顺序上遍历语句树，生成 C++ 片段字符串与计算信息（含复位/数组处理/常量拼接等），存入 `SuperNode::insts`。

17) `cppEmitter`  
    - 分配 `cppId`、激活标记与重置函数，输出最终头/源文件，驱动调度、内存读写、寄存器更新等运行时逻辑。
